## Photo suite

A set of on-device photo tools that share one idea: do the work on the phone, without a server and without heating it up.

- [swift-vision-photo-dedupe](https://github.com/nilkanthdesai76/swift-vision-photo-dedupe) finds similar and duplicate photos and videos with Vision feature prints. Start here.
- [swift-photo-dedupe](https://github.com/nilkanthdesai76/swift-photo-dedupe) is the perceptual-hash approach (dHash, pHash, multi-index hashing).
- [swift-video-dedupe](https://github.com/nilkanthdesai76/swift-video-dedupe) applies temporal fingerprints to video.
- [swift-photo-categorizer](https://github.com/nilkanthdesai76/swift-photo-categorizer) sorts a library into smart albums with Vision.
- [swift-photo-manager](https://github.com/nilkanthdesai76/swift-photo-manager) reads storage and library data through PhotoKit.
- [turbo-photo-sync](https://github.com/nilkanthdesai76/turbo-photo-sync) moves media from Mac to iPhone over a USB tunnel.
